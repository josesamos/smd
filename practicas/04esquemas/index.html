Curso 2024-2025

1 Objetivo

Capacitar a los participantes en el diseño e implementación de esquemas de bases de datos multidimensionales utilizando herramientas como Power BI, Pentaho (Schema Workbench y Aggregation Designer) y R/RStudio, enfocándose en la definición de esquemas para escenarios reales.

1.1 Introducción

Las bases de datos multidimensionales facilitan la transformación de grandes volúmenes de datos en información. En este documento se integran herramientas visuales y de backend para mostrar de forma práctica cómo construir esquemas de bases de datos multidimensionales.

1.2 Contenido

  • Power BI (apartado 2).
  • Pentaho Schema Workbench
  • Pentaho Aggregation Designer, MDX, SQL3 (PostgreSQL)
  • R, RStudio
